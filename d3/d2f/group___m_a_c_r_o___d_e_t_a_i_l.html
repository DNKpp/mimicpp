◆ MIMICPP_DETAIL_COUNTER

#define MIMICPP_DETAIL_COUNTER   __LINE__

General-purpose counter.

This macro generates unique integer values within the current translation unit. Although this mechanism is widely supported, it is not yet part of the official standard. However, a proposal to standardize it has already been accepted, so it is expected to become part of future C and C++ standards.

See also
https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3457.htm

Recent versions of Clang (e.g., Clang 22) may emit the following warning:

error: 'COUNTER' is a C2y extension [-Werror,-Wc2y-extensions]

Since this macro is currently only used to generate unique names for scoped-expectations, falling back to __LINE__ should generally be safe in such cases.

Note
As a last-resort mechanism, users can override this macro by defining it themselves before including this header.
