Detailed Description

template<typename T>
class mimicpp::util::CopyableBox< T >

Simple copyable value type, which owns a heap-allocated value.

Unlike the common std::unique_ptr, this type is directly copyable. Besides that, this type is fully constexpr (unlike std::unique_ptr before C++23).
